1. Period, depth and radius

MATCH
The preprint says
We report a transit-like signal with period P = 5.450138 ± 0.000016 d and depth 196 (+24 / −21) ppm on the K dwarf TOI-913 (TIC 407126408; V=10.5, d=65.2 pc), which hosts the confirmed sub-Neptune TOI-913 b (P = 11.0994 d).
The signal was found by an automated multi-sector search of TESS 2-minute photometry spanning Sectors 12–102 (2019–2026; 34 transits) and corresponds to a radius of 1.12 ± 0.09 R_⊕ if it arises on the target.
The source holds

paper/data/transit_fit.json → joint → P5.4501 (16th, 50th, 84th percentiles)

period [5.45012366143226, 5.450138163851663, 5.450155846170644]
depth_ppm [175.2, 196.1, 220.4]
k (Rp/R★) [0.01324, 0.014, 0.01484]
R★ 0.732535 R☉ (pipeline_signal.json → star.rad)
From one to the other
P = 5.450138 ± 0.000016 d
depth = 196 +24 / −21 ppm
Rp = k × R★ × 109.08 = 0.01400 × 0.7325 × 109.08 = 1.12 R⊕
The ±0.09 also carries R★'s own uncertainty, which isn't in this file (paper/code/transit_fit.py).

You should be able to say: Depth is (Rp/R★)². 196 ppm on a 0.73 R☉ star is a planet about Earth's size. You did this in hand check 1. (guide §1, §4)

Would worry you: A radius that doesn't follow from k and R★.

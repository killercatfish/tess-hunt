tess-hunt

A home pipeline that searches NASA TESS light curves for small transiting planets and then tries to kill every signal it finds. Code lives here on the Mac. Runs happen on Cortex (~/dev/tess-hunt), whose run data stays there.

Scripts

  • run.sh · status.sh · pause.sh · resume.sh · setup.sh: run control on Cortex
  • scripts/audit_from_mac.shRuns the Claude audits on survivors from the Mac
  • scripts/pixel_vet.pyOne-off: difference-image target vs neighbour test
  • scripts/centroid_per_sector.pyOne-off: per-sector centroid of the dip, scored against each star, error bars calibrated by injection into off-transit stacks
  • scripts/transit_fit.pyOne-off: joint transit fit with stellar-density check
  • scripts/robustness_check.pyOne-off: detrending, product and jackknife variants
  • scripts/triceratops_fpp.pyOne-off: TRICERATOPS false-positive probability
  • scripts/neighbour_geometry.pyOne-off: can a neighbour star physically make this transit duration?
  • scripts/periodogram_fap.pyOne-off: GLS, window, dump periodograms and a TLS false-alarm test on shuffled light curves
  • scripts/inversion_test.pyOne-off: TLS on the inverted light curve with the same masks, to see how strong a peak the systematics make
  • scripts/periodogram_fig.pyOne-off: the four-panel figure from that output
  • scripts/preregister.pyPredicted transit times (BJD and UTC) for a future sector
  • scripts/upload_sheet.pyJSON spec to copy-paste HTML sheet for any upload form
